## Project Overview

This project analyzes worldwide Spotify streaming data through an interactive Tableau dashboard designed to explore artist popularity, listener distribution, genre trends, and global streaming patterns.

The solution combines multiple interactive visualizations that allow users to navigate between a global overview of streaming activity and detailed artist-level insights.

The objective was to transform a public dataset into a Business Intelligence solution that supports exploratory analysis and data-driven storytelling. 

![Dashboard Demo](gifs/Dashboard-demo.gif)

## Business Questions

This dashboard was designed to explore questions such as:

- Which artists generate the highest global streaming activity?
- Which countries contribute the most to streaming volume?
- Which genres dominate worldwide listening?
- How does an artist's popularity vary across regions?

## Dashboard Features

The dashboard includes:

- Global overview of streaming performance
- Artist-level drill-down analysis
- Geographic visualization of streaming activity
- Genre distribution analysis
- Interactive filters for dynamic exploration
- KPI cards highlighting key metrics

## Technologies Used

- **Tableau** — Interactive dashboard development and data visualization.
- **Spotify Public Dataset (Kaggle)** — Public data source.
- **SQL** — Basic calculated fields, aggregations, and conditional logic (e.g., `SUM`, `CASE`, `WHERE`) to support custom metrics.
